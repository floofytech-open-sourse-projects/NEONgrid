NeonGrid

NeonGrid is a cyberpunk-themed, Ruby-powered terminal RPG set in an infinite procedural world of glowing grids, rogue code, and mythic mascots. You play as a Gridwalker tracing the last clean language — Ruby — through a collapsing digital city.

Concept

NeonGrid blends:

Terminal-based movement and combat

Procedural infinite world generation

Turn-based party battles

Lore-driven mechanics

JSON save/load system


-Core Features

45 recruitable characters across shops, story, and world events

Lydia: immortal husky, Bio-Fang Prime, central to the lore

The Fang: ruby-red karambit weapon, unique to Lydia

Infinite world: procedural grid with NPCs, enemies, bosses, and rare events

Combat system: turn-based, class skills, meds, revives, auto-retry

Party management: swap active members, prevent duplicates

Shops: recruit allies, buy meds and revive kits

Bosses: Overseer Zero, Garbage Collector v9.1, Infinite Loop Titan

Save/load: JSON-based persistence

Controls

WASD: move instantly via io/console

J: open shop

P: manage party

R: use revive kit

K: save game

L: load game

Q: quit
